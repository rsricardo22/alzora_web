# Estructura del proyecto

- `src/components/`: componentes de interfaz reutilizables.
- `src/config/site.ts`: identidad, dominio, contacto y navegación centralizados.
- `src/data/services.ts`: contenido estructurado de los cinco servicios.
- `src/layouts/`: layout global, metadatos y datos estructurados.
- `src/pages/`: rutas públicas y generador del sitemap.
- `src/styles/`: variables visuales, utilidades y estilos globales.
- `functions/api/contact.ts`: endpoint real de Cloudflare Pages Functions.
- `public/brand/`: logotipo temporal, favicon y recurso Open Graph.
- `public/images/`: ubicación para futuros recursos optimizados.
- `scripts/`: verificaciones automáticas del resultado estático.
- `docs/`: despliegue, estructura y checklist.

El logotipo incluido está identificado dentro del SVG como temporal. Para reemplazarlo se recomienda conservar los nombres de archivo y sus proporciones, o actualizar las referencias en los componentes.
